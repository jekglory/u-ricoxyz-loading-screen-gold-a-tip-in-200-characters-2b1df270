Pure-stdlib Python; the program writes the tip to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), deterministically.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
